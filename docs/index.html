Compatível com OpenAI Codex + VS Code

MAESTRO / CODEX

Kit de configuração de 9 subagentes, 19 skills e workflows para desenvolvimento full stack, QA, segurança, documentação e deploy em VPS Linux sem Docker.

Comece em três passos

1. Abra a pastaExtraia o ZIP e abra a pasta no VS Code.
2. Ative o CodexInstale a extensão oficial `openai.chatgpt` e faça login.
3. Peça ao MaestroNo chat, digite a skill `$maestro` e descreva seu projeto.

Exemplos

Use $maestro para planejar uma plataforma de pedidos e implementar o MVP.
Use $novo-saas para construir um SaaS Django/Next.js.
Use $auditoria-seguranca para procurar riscos, sem alterar produção.
Use $deploy-vps para gerar configurações; não execute remotamente.

Como funciona

O arquivo AGENTS.md define a política, .codex/agents/*.toml descreve 9 especialistas e .agents/skills/ disponibiliza 19 skills. Todas as ações dependem das permissões do usuário. Não há promessa de certificação de segurança ou funcionamento autônomo permanente.

Detalhes no README.md e no manual completo em Markdown. Documentação oficial Codex.

Adaptação de conteúdo de terceiros. Projeto independente, não oficial OpenAI.
